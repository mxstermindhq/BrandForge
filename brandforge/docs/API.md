# BrandForge API & Webhooks (scaffold)

Static export — no server routes. This documents the **content API surface** and **planned webhooks** for Sprint 7+.

## Content modules (build-time API)

| Module | Path | Exports |
|--------|------|---------|
| Content index | `src/content/index.ts` | `getAllContentEntries()`, `CONTENT_STATS` |
| Partners | `src/content/partners/registry.ts` | `PARTNERS`, `AFFILIATE_PROGRAM` |
| Ecosystem | `src/content/shared/ecosystem.ts` | FAQs, case studies, testimonials |
| Sitemap | `src/app/sitemap.ts` | Auto from content index |
| llms.txt | `public/llms.txt` | Generated by `scripts/generate-llms-txt.mjs` |

## GA4 events

| Event | When |
|-------|------|
| `cross_platform_nav` | BrandForge ↔ MXSTERMIND link click |
| `partner_referral` | Inbound `?ref=` or outbound partner click |
| `page_conversion` | Any CTA click with `page_path` |
| `resource_download` | PDF / lead magnet download |

## Webhooks (optional env)

| Webhook | Env var | Payload |
|---------|---------|---------|
| Discord deploy | `DISCORD_WEBHOOK_URL` | Deploy / weekly / fail summaries |
| Partner apply | `DISCORD_PARTNER_WEBHOOK_URL` | Future static form POST |
| Client feedback | `DISCORD_CLIENT_WEBHOOK_URL` | Future /client/ form |

## Onboarding flow (documented)

1. Package selection → `click_package_tier`
2. Brand questionnaire → Discord thread or Typeform embed
3. Payment → Stripe link or crypto/escrow manual confirm
4. Kickoff → auto-post template to internal Discord (manual copy today)

## Headless CMS (future)

When content exceeds file-based scale, migrate `src/content/*` to Sanity/Contentful with build-time fetch — sitemap and llms.txt generators already centralised in `scripts/`.
